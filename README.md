# 🚪 GateFlow - Digital Gate Pass Management System

A responsive JavaScript web application to automate, track, and manage visitor and student digital gate passes seamlessly.

---

## ✨ Features
- Digital pass generation with auto timestamps
- Local data persistence (LocalStorage)
- Search and filter records
- Responsive and clean UI

---

## 🛠️ Tech Stack
- HTML5, CSS3
- JavaScript (ES6)
